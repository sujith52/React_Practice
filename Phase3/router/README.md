## Phase 3: Routing, Forms & Real App Structure (2 weeks)
<h1><a href="https://wondrous-tulumba-e8ae58.netlify.app">Live Demo</a></h1>

- **React Router**: routes, nested routes, `Link/NavLink`, `useParams`, `useNavigate`, `useSearchParams`
- Protected routes, 404 page, layouts with `<Outlet />`
- Lazy loading routes (`React.lazy` + `Suspense`)
- **Forms done properly**: **React Hook Form + Zod** validation
- Folder structure for bigger apps (feature-based)
- Error boundaries
- Environment variables (`.env`, `import.meta.env`)
- Reusable UI components (Button, Modal, Input, Card)
- Component libraries: **shadcn/ui** or MUI (learn one)
